# Lygių iliustracijos

Originalūs 640 × 200 SVG be teksto:

- `a1plus.svg`: kavinė ir pirmieji užsakymai; `#1f9d8a`.
- `a2.svg`: traukinys ir žemėlapis; `#5b4fd6`.
- `a2plus.svg`: du žmonės kalbasi mieste; `#d9632b`.
- `b1.svg`: savarankiška diskusija ir aiškinimas; `#c23b7a`.

Failai įtraukti į offline talpyklą. Esamas `viewPath` jų dar nerodo. Claude gali įterpti atitinkamą `<img>` į `.level-head`, tačiau šiame išteklių pakeitime `js/app.js` nebuvo redaguotas.
