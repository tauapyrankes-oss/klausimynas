# Trumpi garsai

Originalūs, sintezuoti garsai be išorinių įrašų ar mėginių. Mono MP3, 22,05 kHz, 48 kb/s; kiekvienas mažesnis nei 20 KB.

- `correct.mp3`: trumpa kylanti dviejų natų frazė.
- `wrong.mp3`: švelni žemėjanti frazė, be baudžiančio signalo.
- `levelup.mp3`: trumpas keturių natų pakilimas.

Failai įtraukti į offline talpyklą. Viktorinos jų dar negroja: pagal `codex/README.md` garsų prijungimui reikėtų pakeisti `renderQuiz`. Tai palikta Claude; mokymosi logika šiame pakeitime nepaliesta. Jungiant pridėkite garso išjungimo nustatymą ir grokite tik po vartotojo veiksmo.
